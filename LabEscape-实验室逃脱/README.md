# 实验室逃脱(LabEscape)

Bearcade 小游戏包:圆环上均匀分布柱子,玩家从柱顶挖到底部,跑向中央圆形塌陷区跳下,比谁先完赛。

## 玩法

- **人数/房间**:2~16 人 / 4 房 / 支持派对模式(派对可生成更多柱子,最多 40)。
- **地图**:
  - 圆环上均匀分布 N 根 1×1 柱子,每根 50 格高,由沙子/原木/石头**每格随机**构成;
  - 每根柱子被 3×3 不可破坏玻璃方管围住,底部留 2 格开口;
  - 场地中央有一个预挖好的圆形塌陷区。
- **流程**:
  - 每人开局在自己柱顶,获得无限耐久钻石镐/铲/斧;
  - 只能挖掘自己柱子内的沙子/原木/石头,不能放置方块;
  - 挖到底部后从玻璃底部出口跑向中央,跳入塌陷区;
  - 第一名跳入后,游戏进入 15 秒最后冲刺,其他玩家可继续完赛;
  - 105 秒内无人完赛则本局无获胜者;结束后展示前三名,并给每个玩家显示自己的名次或“未完赛”。
- **意外处理**:死亡/被沙子埋住会恢复到当前柱子顶部(柱子当前最高点)继续。

## 地图构建指令

地图**不在对局中生成**,由管理员在模板维度手动生成:

```text
/bearcade:tmp tp labescape        # 进入模板维度
/labescape:build 16               # 生成 16 柱地图(普通模式)
/labescape:build 40               # 生成 40 柱地图(派对模式,最多 40)
/bearcade:tmp sz labescape        # 用表单确认/调整模板捕获范围
/bearcade:tmp ap labescape        # 应用到全部 4 个房间
```

> `/labescape:build` 需要 `op` tag,并且只能在模板维度 `bearcade:labescape_template` 执行;不传数量时默认 16。

## 常用命令

- `/labescape:build <数量>`:在模板维度生成地图;
- `/bearcade:config labescape`:运行时配置(对局中禁止修改);
- `/bearcade:quit`:在房间维度强制中止;
- `/bearcade:debug labescape enable|disable`:调试日志。

## 可配置项(经 `/bearcade:config labescape`)

普通模式最大人数(默认 16)、派对模式最大人数(默认 40)、准备房间坐标、地面 Y、柱子高度、玻璃底部开口高度、中央塌陷区半径/深度、完成判定深度、最小环半径、柱间距、环半径覆盖(0=自动)、游戏时长(默认 105s)、第一名后倒计时(默认 15s)、派对最大柱子数(默认 40)。

详细规范见仓库根目录 `development.md`。
