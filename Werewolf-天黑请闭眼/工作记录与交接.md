## 1. 一句话现状

《天黑请闭眼》是 Bearcade 下的 6~10 人派对推理小游戏:4 个房间,每房 10 人上限、6 人开局;身份含平民/警察/守卫/杀手/狙击手;夜间五阶段(狙击手→守卫→杀手→警察)→ 白天讨论公投,循环至一方胜利。玩法基于旧版《天黑请闭眼[灯塔镇文化艺术筹划组]》的规则与围桌场地重制,但**全部用 ScriptAPI 重写**,不再使用命令方块、JS 插件(LLSE/BDS 插件)或原版物品交互。

## 3. 已确认需求清单(逐条,来自用户)

### 3.1 核心规则(用户口述 + 旧版规则,已确认)
1. 十人局:平民×4、警察×2、守卫×1、杀手×2、狙击手×1(狙击手 2 发子弹);
2. 6~10 人职业表(见 §4.1);
3. 好人胜:**全部杀手出局**;坏人胜:**全部平民出局 或 全部警察出局**(6~10 人通用,不按固定人数);
4. 夜晚顺序:狙击手 30s → 守卫 30s → 杀手 60s → 警察 60s → 白天 90s → 循环;
5. 狙击手任意夜晚可开枪,共 2 发(按表);
6. 守卫不可连续两晚保护同一人;只挡杀手,不挡狙击手/公投;
7. 杀手两人选同一人才击杀;**只有一人行动 → 按该选择生效**;**两人选不同 → 击杀失败**;不可杀自己/队友;
8. 警察两人选同一人直接查验;**只有一人行动 → 按其选择**;**两人选不同 → 随机查其一**;不可查自己/队友;结果只给警察;
9. 白天平票/无人投票 → 无人出局;
10. 警察与杀手内部互相知晓;狙击手不属于互相知晓范围,且**无队内聊天**。

### 3.2 用户后续明确的需求(按时间顺序)
1. 先搭骨架,4 房/10 人上限/6 人开局倒计时;
2. 座位 = 场地色块,左→右:**绿1、浅蓝2、红3、粉4、黄5、白6、青7、紫8、深蓝9、黑10**;
3. 6 人局站中间六席(红粉黄白青紫),7 人右侧加深蓝,8 人左侧加浅蓝,9 人右侧加黑,10 人左侧加绿;
4. **号码永远从 1 号顺序排**(不是色块号码),只是站到上述中间色块;颜色跟随所站色块(6 人局 1 号=红、2 号=粉……);
5. 名牌用 nameTag 染色,号码用 **TextPrimitive 头顶浮空字**(参考旧版 title.js);
6. 开局后锁定全场固定视角(旧版同款机位);**所有玩家都锁,包括 op**;
7. 开局后禁止玩家移动:用 **inputPermissions** 禁用,不是持续 tp;离场/回大厅/结束必须恢复;
8. 夜晚公告**不得公布行动者姓名**(会公开身份);
9. 投票物品不用原版物品:先用钟→用户担心与大厅钟冲突→换望远镜→用户仍担心干扰→最终**自定义物品 `bearcade:werewolf_vote`**;
10. 死亡后:
    - 遗言 TextPrimitive 浮空字(参考旧版 testament 功能,但用 TextPrimitive 实现);
    - **遗言下方写明身份**,颜色:平民白、警察浅蓝、守卫黄、杀手浅红、狙击手深红;
    - 退出/断线视为出局、对局继续、**无遗言**;
11. 白天公投时,谁被投了票,在其**遗言生成位置**标明(实时「获 N 票」);
12. 出局玩家**本局禁言**(公开+队聊全部拦截);
13. 公开聊天显示**聊天气泡**(参考旧版 chatbubble.js;队聊不显示气泡,防泄露)。

### 3.3 开发侧确认过的取舍
- 死亡即公开身份(沿旧版);结束揭晓全部身份;
- 夜晚阶段无对应行动者/子弹时自动跳过并公告;
- 守卫不可自保;杀手/警察不可选队友;狙击手可误杀杀手(不认识);
- 准备倒计时沿用共享运行时默认:60s、满 10 人压 5s、调试模式 10s;
- 白天的"发言"与"投票"不拆分,共 90s;
- 阶段时长做成 `/bearcade:config werewolf` 运行时可改。

### 4.2 身份颜色(最终版)

| 身份 | 颜色码 | 用途 |
| --- | --- | --- |
| 平民 | `§f` 白 | 身份牌/公告/私聊 |

### 4.4 座位分配(最终规则)

- 玩家号码 = 入场顺序 1~N;
- 站到中间色块:物理座位由 `USED_SEATS[人数]` 决定:
  - 6:[3,4,5,6,7,8] → 1号红、2号粉、3号黄、4号白、5号青、6号紫
  - 7:[3..9] → 7号深蓝
  - 8:[2..9] → 1号浅蓝,2号红……8号深蓝
  - 9:[2..10] → 9号黑
  - 10:[1..10] → 1号绿……10号黑
- `member.color = PAD_COLORS[物理座位]`;名牌/聊天前缀/投票物品/头顶号码都用这个颜色;
- 投票物品显示「投给 N号」且按目标颜色着色,号码是顺序号(不是物理座号)。

### 4.5 昼夜流程(实现:src/game.ts 状态机)

阶段数组:`["sniper","guard","killer","police","day"]`,白天结束回狙击手,`night` 从 1 开始计数。

每个阶段进入时(`enterPhase`):
1. 自动跳过无行动者阶段(狙击手无子弹/已死、守卫已死等;杀手/警察为 0 时理论上胜负已判,防御性跳过);
2. 清空全员背包 → 发投票物品(候选=存活且符合规则)→ 清空选择 → 清投票浮空字;
3. 全房公告:只写「第 N 夜 · XX身份行动中(时长)」,**不写行动者姓名**;
4. title/actionbar 提示(行动者看到自己行动提示);
5. 重锁全场相机。

结算(时间到):
- 狙击手:有有效选择且子弹>0 → 击杀、子弹-1;否则"没有开枪";
- 守卫:有效选择 → 记录本夜守护座号 + 上一夜冷却座号;未选 → 清空且**不占用冷却**;
- 杀手:存活杀手选择取集合;0 个→没行动;1 个→击杀;>1 个→分歧失败;若目标=守护座号→格挡公告;
- 警察:存活警察选择取集合;0 个→没查验;1 个→查该人;>1 个→随机其一;结果只发存活警察;
- 白天:统计存活玩家投票;最高票唯一→出局;否则平票/无人投票无人出局。

### 4.6 出局流程(`eliminate`)

1. `alive=false`,清空该玩家选择;
2. 清背包、冒险模式、隐身(无粒子)、actionbar「你已出局」;
3. 全房公告出局原因 + 身份揭示;
4. 生成**身份牌浮空字**(y+2.0,颜色按 §4.2);
5. 若允许遗言(被狙/被杀/被公投):弹表单 → 提交后在 y+2.6 生成「遗言是 xxx」(空="空",最长 50 字)并公告;
   - 退出/断线:无遗言表单,但仍有身份牌与公开身份;
6. 立即检查胜负。

### 4.7 离场处理(退出=出局、对局继续)

- 共享运行时新增 `MinigameConfig.endGameWhenBelowMin`(默认 true;werewolf 设 false),运行时不再因人数低于 6 自动结束;
- werewolf 主循环每 10 tick 检查 session 成员是否仍在房间,不在则:
  - 通过 `world.getAllPlayers()` 找到对象时,恢复 Movement/Camera 输入权限;
  - 移除头顶号码与气泡;
  - 按"离开了游戏(视为出局,无遗言)"走 eliminate;
- 另有 `playerDimensionChange`/`playerLeave` 兜底恢复权限与清气泡。

### 4.8 胜负

每次有人出局后 `checkWin`:
- 存活杀手 = 0 → 好人胜「警察阵营胜利」;
- 存活平民 = 0 或 存活警察 = 0 → 坏人胜「杀手阵营胜利」;
- 胜后:公告全部身份(号+名字+身份+存活状态)→ `runtime.endGame` → 约 3 秒后全员回大厅,房间从模板重建。

### 4.9 相机与移动锁定

- 相机:`player.camera.setCamera("minecraft:free", { location:(3,-55,0), facingLocation:(-7,-55,0), easeOptions:{easeTime:0.3, easeType:EasingType.Linear} })`;
- **所有玩家锁定(无 op 例外)**;
- 时机:开局立即 + `runTimeout` 2/10 tick 补锁 + 每阶段开始 + 主循环每 20 tick 重锁;
- 失败打 `[Bearcade werewolf] 相机锁定失败:<玩家名>` 日志;
- 移动:开局 `inputPermissions.setPermissionCategory(Movement,false)` + `(Camera,false)`;
- 恢复:`playerDimensionChange` 离开房间、离场玩家、`onBeforeReset` 三处都恢复;重置时 `camera.clear()`。

### 4.10 聊天系统

- 公开聊天:放行 + 头顶聊天气泡(5 秒/100 tick、最多 5 条、base y 2.8、间距 0.4、黑底 α0.45,`attachedTo` 玩家,参考 chatbubble.js);
- 队聊:`!内容` 开头 → 取消公开、只发给同队存活玩家(仅杀手/警察;狙击手无队聊;**不生成气泡**);
- 出局禁言:公开与队聊全部 `event.cancel`,提示「你已出局,本局禁言」;
- 离开房间/断线清气泡。

### 4.11 投票物品(最终方案:自定义物品)

文件:`items/werewolf_vote.item.json`
- `identifier: bearcade:werewolf_vote`;
- `max_stack_size:1`;icon 暂用 `paper` 纹理;cooldown 0.2s(独立 category);
- `minecraft:on_use` → 事件 `bearcade:on_use` → `run_command: scoreboard players set @s ww_click 1`(旧版同款机制,保证右键可靠触发 `itemUse` 事件);
- 脚本启动时预建 dummy 计分板 `ww_click`;
- 脚本只认 `event.itemStack.typeId === ACTION_ITEM`,再按 nameTag 分「投给 N号」/「取消选择」;锁槽(`ItemLockMode.slot`)。

## 8. 构建、部署与验证

### 8.1 标准命令
```bash
npm run typecheck   # TS 类型检查
npm run check       # packId 一致性(含 werewolf)
npm run build       # esbuild 打包 + 生成 manifest
npm run package     # 产出 dist/packages/werewolf.mcpack 与 bearcade.mcaddon
```
