# 急速战桥(BridgeWar)

Bearcade 小游戏包(开发中)。房间管理复用 `shared/minigame-core`,玩法在 [src/game.ts](src/game.ts)。

## 已确认规则

- 每房 2~8 人,4 个房间,支持派对模式;
- 玩家随机平分红蓝两队(奇数人数随机一队多一人),队伍固定不换;
- 进入对方核心区得 1 分队分,回合立即结束;先到 5 分队胜;
- 无回合时限;每回合结束清空实体并从模板重置地图,全员回各自基地;
- 掉入虚空 3 秒后在自己基地复活,复活期间不能得分;
- 禁止破坏地图本体方块,但**可以放置方块、破坏玩家放置的方块**(搭桥/拆桥);
- 玩家聊天名字按队伍颜色渲染(红/蓝),sidebar 显示两队比分与目标分;
- 核心区/出生点/获胜分数可通过 `/bearcade:config bridgewar` 在游戏内配置(代码默认值在 `src/config.ts`);模板场地建好后核对。

详细规范见仓库根目录 `development.md`。
