# 杀年猪(NewYearPig)

Bearcade 小游戏包:**45×45 草方块地皮上限时击杀动物得分**。房间管理复用 `shared/minigame-core`,玩法在 [src/game.ts](src/game.ts)。

## 玩法规则

- 每房 **2~8 人**,共 **4 个房间**,一局 **90 秒**(可配置),支持**派对模式**;
- 地图为 **45×45 草方块地皮**,由模板维度指令生成;
- 动物持续刷新:开局先刷一小批,之后每秒按人数生成几只;场上动物有数量上限;
- 开局每人获得一把**不可破坏的木剑**(锁定快捷栏第 1 格),保留原版攻击/受击表现;
- 动物类型与分值:
  - **鸡**:绿色 `+1`,玩家击打 **1 次**击杀;
  - **猪**:黄色 `+5`,玩家击打 **2 次**击杀,常驻速度 IV;
  - **羊**:橙色 `+3`,玩家击打 **2 次**击杀,常驻速度 III;
- 动物头顶悬浮字使用 `TextPrimitive.attachedTo` **直接绑定实体**,随动物移动;
- 约 **20%** 动物头顶为红色 `-50%`,击杀后**当前总分四舍五入减半**;
- 猪/羊受到攻击后会受惊逃跑(默认 15 秒后恢复,可配置为一直逃跑);
- **特殊事件**:
  - 剩余 70~50 秒与 40~20 秒时,分别随机刷新一把**只剩 3 耐久的钻石剑**,刷新时公告并放烟花;
  - 剩余 40~20 秒的另一随机时刻,场地中央刷新 **“牛来”**:25 HP、速度 VI、`+10` 大字悬浮字,并公告;
- **玩家之间禁止互相伤害**;
- 对局中玩家持续拥有**饱和效果**,不会饿死;
- 对局结束后会**清理全部动物、掉落物与经验球**;
- 右侧 HUD 显示**当前前三名分数**,Actionbar 显示**自己的分数**;
- 游戏结束公布**前三名**并返回大厅。

## 模板地图生成

在模板维度执行(管理员,需要 `op` tag):

```text
/bearcade:tmp tp newyearpig
/bearcade:newyearpig_buildmap
```

生成 45×45 草方块地皮;之后用 `/bearcade:tmp sz newyearpig` 配置模板范围,再 `/bearcade:tmp ap newyearpig` 应用到全部房间。

## 运行时配置

`/bearcade:config newyearpig`(对局中禁止修改),可配置:

- 准备房间坐标;
- 地图原点/边长;
- 一局时长、开局动物数、生成间隔、每批数量、人数加成、场上动物上限;
- `-50%` 动物概率;
- 受惊逃跑秒数(0 = 一直跑)与冲量强度;
- 鸡/猪/羊分值;
- 生成权重;
- 特殊事件(钻石剑耐久、牛来血量/分值/速度、事件时间窗);
- 恢复默认。

## 常用命令

- `/bearcade:tmp tp newyearpig` / `sz` / `ap`:模板维度开发;
- `/bearcade:newyearpig_buildmap`:模板维度生成草方块地皮(管理员);
- `/bearcade:config newyearpig`:运行时配置;
- `/bearcade:quit`:在房间维度执行,强制中止对局;
- `/bearcade:debug newyearpig enable|disable`:调试日志。

详细规范见仓库根目录 `development.md`。
