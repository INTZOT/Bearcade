# 《剑与消亡V：上密会战（Sword & Dissolution V : Battle of Upper Mysiaen）》（SND5）·学派战技能包（基岩版 1.26.40）

行为包 + 资源包 + 脚本。使用 `build.ps1` 打包为 `.mcaddon`。

## 使用方式

- 第一次进服会弹出选择菜单：选择 1 个学派 + 2 本圣典/法典/秘典。
- 各学派技能与圣典均为独立物品，手持后电脑端右键 / 手机端长按使用。
- 物品冷却由物品自带冷却显示，CD 从使用物品时开始计算。
- 队伍：默认按进服顺序交替分配红/蓝队（占位方案），聊天栏输入 `!team red` 或 `!team blue` 可切换。
- 所有玩家出生/复活时获得生命提升 V 并回满血（祝福期间临时提升为生命提升 VIII）。

## 效果换算约定

文档中“效果\*N”均按 N+1 级实现（\*0 = I 级，\*1 = II 级，依此类推）。
