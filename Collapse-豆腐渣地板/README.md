# 豆腐渣地板(Collapse)

Bearcade 派对小游戏包:踩过的地板会塌陷,别停下!最后存活者获胜。

房间管理通用逻辑(维度注册、模板复制、状态机、上报、命令等)统一封装在仓库 `shared/minigame-core`,由构建工具内联进本包——修改共享代码后重新 `npm run build` 即可同步全部小游戏包。

## 玩法

- **塌陷地板**:开局全员站在白色混凝土地板上;玩家脚下 3×3 范围内的地板被踩后进入塌陷状态(黄 → 橙 → 红 → 消失),每阶段默认 1 秒(可配置),离开后继续塌;
- **多层场地**:层数由模板场地决定,塌陷会逐层向下传递,越踩越危险;
- **PVP**:开局 60 秒(可配置)后开启,可以徒手把对手打下地板;
- **淘汰**:掉到虚空淘汰高度(默认 y=-20,可配置)以下即淘汰 → 传送到观战台,进入 **follow_orbit 环绕观战**(引擎原生:围绕存活玩家公转、鼠标可自由环绕视角、跟随移动零抖动;切换目标/目标被淘汰时 0.5s 平滑运镜飞向新目标),手持望远镜可切换观战对象(望远镜槽位锁定,无法丢弃);
- **胜负**:最后 1 名存活者获胜;全员淘汰则平局;离开房间/掉线一律视为淘汰。

## 参数

默认配置见 [src/config.ts](src/config.ts),运行时可经 `/bearcade:config collapse` 调整(对局中禁止修改):

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 准备房间坐标 | 占位 | 大厅入房传送点,需按模板场地填写 |
| 场地中心 | 占位 | 场地中心 x/z,塌陷检测与出生点基准 |
| 顶层地板 Y | 占位 | 顶层地板高度,出生与场地范围基准 |
| 场地大小 | 19 | 单层白色混凝土地板边长(奇数),3~63 |
| PVP 开启延迟 | 60 秒 | 开局后开启 PVP 的秒数,10~300 |
| 塌陷阶段时长 | 1 秒 | 黄→橙→红 各持续秒数,之后消失,1~10 |
| 虚空淘汰高度 | -20 | 掉到该 y 以下即淘汰,-64~64 |
| 观战玩家位置 | 占位 | 淘汰玩家本体传送位置(观战台) |

房间数 2,支持 2~16 人,派对模式可用(`PARTY_AVAILABLE=true`)。

> **观战依赖(部署必读)**:follow_orbit 观战需要世界开启实验开关 **"Creator Cameras: New Third Person Presets"**(世界级、开启后不可逆,建图时就开)与世界作弊(`/camera` 命令需要);观战使用内置 `minecraft:follow_orbit`(环绕半径/几何由引擎决定),切换目标时的运镜起点由 `src/game.ts` 的 `ORBIT_RADIUS` 等常量控制。

## 场地制作(首次运行前必做)

当前 `src/config.ts` 中场地坐标均为**占位值**,模板场地建好后需核对/调整:

1. `/bearcade:tmp tp collapse` 进入模板维度 `bearcade:collapse_template`;
2. 建造多层白色混凝土场地(层数决定玩法深度,层间留空以便坠落;顶层建议 19×19 左右,与默认 `ARENA_SIZE` 匹配);
3. `/bearcade:tmp sz collapse` 用表单配置模板捕获范围(起始点/终点),`/bearcade:tmp ap collapse` 应用到全部房间;
4. `/bearcade:config collapse` 核对并修改:准备房间坐标、场地中心、顶层地板 Y、场地大小、观战台位置;
5. 完成后房间状态应变为"空闲",即可从大厅钟菜单进入游玩。

> 模板横向超过 64 无需额外处理:共享运行时按 `tileSize`(默认 64)自动分块捕获与放置;模板维度必须常加载。

## 常用命令

- `/bearcade:tmp tp collapse` / `sz` / `ap`:模板维度开发(制作场地);
- `/bearcade:config collapse`:运行时配置(对局中禁止);
- `/bearcade:quit`:在房间维度执行,强制中止对局;
- `/bearcade:debug collapse enable|disable`:调试日志。
