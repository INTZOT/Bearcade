# 中国象棋(CChess)

Bearcade 小游戏包:9×10 传统中国象棋,红先黑后,吃帅/将即胜。房间管理复用 `shared/minigame-core`,玩法在 [src/game.ts](src/game.ts)。

## 已确认规则

- 每房 2 人(红/黑),8 个房间,开局随机分配颜色;
- **操作**:**操作木棍**(快捷栏第 1 格)右键=在**玩家所在格**选中/走子(itemUse 驱动,与 Go 落子同构,对空右键也触发);走到己方棋子格右键=选中(显示合法走法粒子:可走白框/可吃红框),走到目标格再右键=走子;非法走法拒绝并保持选中,右键己方另一棋子=切换,右键同格=取消;
- **规则完整**:车/马(蹩腿)/炮(隔山)/相(塞眼不过河)/仕/帅(九宫)/兵(过河前直进、过河后可横、不可退);**禁送将**与**将帅照面**校验;落子将军自动播报"将军!";
- **棋谱播报**:传统记谱(兵三进一 / 车二平五 / 马八进七),同列同名棋子自动加"前/后",吃子附加",吃X";
- **胜负**:吃帅/将即胜;每方局时(默认 10 分钟,可配置)超时判负;`book`=认输;`glass_bottle`=求和(对方弹窗确认,双方同意=和棋);离开房间视为认输;
- **俯瞰视角**(复用 Go 模式):望远镜(快捷栏第 8 格)右键切换,相机位于棋盘正上方、**红黑双方视角不同**(红方画面旋转 180°),锁 60 视野;俯瞰下操作方式不变(**木棍右键=玩家所在格**),脚下格有白色粒子框提示(普通视角同样显示,双方均可见);
- 棋盘为**死场景**(放置/破坏全拦截),每局结束模板重放恢复初始布局,零代码清理。

## 场地制作

棋盘在模板维度 `bearcade:cchess_template` 制作:9 列 × 10 行棋盘格(y 63~64,范围 ±7),按标准布局摆放初始棋子(黑方 z=0 行:将士象马车炮卒,红方 z=9 行:帅仕相马车炮兵);`/bearcade:tmp tp cchess` 进入,`sz` 配范围,`ap` 应用。

## 常用命令

- `/bearcade:tmp tp cchess` / `sz` / `ap`:模板维度开发;
- `/bearcade:config cchess`:棋盘位置/俯瞰高度/红黑开局坐标/局时;
- `/bearcade:quit`:强制中止对局。

详细规范见仓库根目录 `development.md`。
