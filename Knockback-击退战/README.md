# 击退战(Knockback)

Bearcade 小游戏包:**个人混战,中央高台停留得分,用击退木棍把别人推下高台**。房间管理复用 `shared/minigame-core`,玩法在 [src/game.ts](src/game.ts)。

## 已实现规则

- **人数/房间**:2~8 人 / 4 房 / 支持派对模式(派对无视人数上限);
- **场地**:中央圆形高台(半径 7)比外围高一格,外围半径约 16,边缘用方块围一圈防止掉落;中央高台再高一格的位置有一个半径 3 的「1.5 倍得分区」;
- **计分**:每 0.1 秒计算一次,站在中央高台范围内 +0.1 分(即每秒 +1 分);站在 1.5 倍得分区 +0.15 分(即每秒 +1.5 分),多人同在各自加分;
- **击退木棍**:
  - 所有玩家开局获得 1 根「弱击退木棍」:无耐久,可无限使用;
  - 场地中央高台和外围都会刷新「中级击退木棍」和「强力击退木棍」,耐久较耐用(比上一版略减一点);
  - 三种木棍使用不同材质(弱=棕色、中=绿色、强=红色),一眼可辨;
  - 拾取更强木棍会自动替换当前木棍,并统一放到快捷栏第 1 格;
  - 攻击不掉血,只造成击退;中/强木棍会消耗耐久,损坏后自动换回弱击退木棍;
  - 每次刷新中/强木棍时,聊天栏会公告“XX木棍在场上出现!”;
  - 摔落不掉血;
- **时长**:默认 90 秒,结束后按分数排名,并列获胜;剩余 60/30/15/10/5/4/3/2/1 秒时聊天栏提醒;
- **开局**:先显示一次“击退战”标题并倒计时 3 秒,倒计时期间禁止移动,结束后才开始计分;
- **显示**:自己的得分显示在 actionbar(加粗);其他玩家名字下方用浮空字显示对方分数(不显示自己的头顶分数)。

## 当前状态

- 玩法逻辑已实现,场地坐标仍为**占位值**,需要在模板维度建好场地后核对/调整 `src/config.ts`;
- 自定义物品已添加:
  - `bearcade:knockback_stick_weak`
  - `bearcade:knockback_stick_medium`
  - `bearcade:knockback_stick_strong`
- 三个木棍使用自定义材质(弱=棕、中=绿、强=红),资源包已包含对应贴图。

## 开发流程

1. `/bearcade:tmp tp knockback` 进入模板维度建场地(中央高台 + 外围 + 边界墙);
2. 模板范围用 `/bearcade:tmp sz knockback` 表单配置起始点/终点;
3. 场地改好后 `/bearcade:tmp ap knockback` 一键应用到全部房间;
4. 在 [src/config.ts](src/config.ts) 填写/核对:场地中心、中央/外围 Y、出生点、准备房间、常加载区域;
5. `npm run typecheck && npm run build && npm run package`。

> 进入模板维度/应用模板/强制中止命令由 **Core 统一提供**:`/bearcade:tmp tp|ap|sz knockback`、`/bearcade:quit`(在对应房间维度执行),小游戏包无需自己注册命令。

## 常用命令

- `/bearcade:tmp tp knockback` / `sz` / `ap`:模板维度开发;
- `/bearcade:config knockback`:运行时配置界面(对局中禁止修改);
- `/bearcade:quit`:在房间维度执行,强制中止对局;
- `/bearcade:debug knockback enable|disable`:调试模式,开启后等待倒计时缩短为 10 秒。
