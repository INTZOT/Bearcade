# 春叶大招粒子与画面氛围提案

2026-09-28，供用户选择设计方向。本文件是后续制作提案，本轮尚未新增粒子、遮罩或文字资产。

**用户明确限制：title 与 actionbar 都已占用，演出层均不可借用，subtitle 也避开。** 前面的 title/actionbar 标记方案均已撤回。当前未找到本项目 API 可直接控制任意 JSON UI 控件的独立接口，不能把“UI 可绘制图片”当作“脚本可直接控制 UI”。

## 整体风格

推荐表现“优雅、克制地操纵叶片与空间，出手瞬间非常坚决”。让末影珍珠成为空间变化的原因，让叶片描出攻击方向。配色以深青绿 `#123D36`、翠绿 `#55BE94` 为主，珍珠附近点少量末影紫 `#8C6CC7`；冲击中心用很小的青白色 `#E4FFF4`。残血分支加深青绿、放慢漂浮的叶片，靠沉静和压迫感区别于普通终结。

角色脸、双手、珍珠及实际接触部位优先保持清楚；叶流尽量放在身体两侧和背后。七次重击分别突出拳弧、踢击斜线、落点冲击，避免每一下都变成同一团覆盖人物的爆炸。

## 推荐的三气演出

| 阶段 | 画面建议 | 同步与尺度 |
| --- | --- | --- |
| 低头 | 几片暗翠叶子从脚边缓慢升起，稀疏光尘向右手收束，背景边缘渐暗 | 利用本轮加长的开场；叶片数量少，脸前留空 |
| 猛抬头 | 手中珍珠出现细小青白亮点，一道短促的弧光划过身后 | 不把整个画面闪白，保持抬头动作可读 |
| 高抛珍珠 | 珍珠带细而连续的青紫尾迹，身旁叶片被带起；高处绽开一圈薄环 | 高处爆开后迅速收束；普通追击阶段恢复清楚的战斗视野 |
| 首拳蓄力与接触 | 叶片逆向收拢到拳侧，出拳后沿命中方向射出细长叶痕；接触点出现小型环形冲击 | 蓄力与快拳形成对比，冲击严格跟随实际接触帧 |
| 后续六次多方位重击 | 落点先出现短促空间裂光，本体出现时绽开少量叶片；拳弧/踢弧各有方向 | 越来越快时缩短粒子寿命，强调节奏而非单纯增加数量 |
| 普通终结下砸 | 身后高处聚出一束狭长青光，击中后叶流向下压向地面，地面薄环向外散开 | 集中增强最后一击；粒子不遮住击倒轨迹 |
| 残血终结提吊 | 双手外侧缓慢旋转两簇叶片，敌人脚下少量叶片被向上带起，环境明显静下来 | 遵守原设计：没有连向脖子的实线，没有频繁乱闪和快速抖动 |
| 残血终结上击 | 叶片先短暂内收，身体接触后迸出斜上方的青白冲击与长叶轨迹 | 展示蓄力后的身体重击；让敌人的高远击飞仍然清楚 |

三气普通命中与 KO 共用主要效果。KO 再利用已有定格/慢放与 KO 字，粒子按对应表现时钟采样，避免角色定住而长尾粒子先播完。粒子系统自身的世界时间不会自动服从脚本慢放，需要通过发射频率、Molang 采样或独立的定格图案来协调，不声称天然同步。

## 一气和二气的区分

- 一气：短珍珠尾迹、瞬移起落点叶片、拳后一道较宽但短命的叶弧。强度集中在单拳，保留快速利落。
- 二气：命令方块周围少量方形符文/像素角标，成功捕获后与现有框体一起向内压缩，压击时出现一圈棱角分明的冲击。失败分支只消散手中聚集效果，不能播放命中框体或终结爆散。
- 三气：拥有更完整的开场氛围、空间落点裂光、多方向攻击痕迹和专属终结。三档保持共同颜色与叶片语言，依靠结构和节奏拉开层次。

## 全局遮罩在基岩版里的实现选择

1. **先做镜头边缘的半透明叶纹/暗角试样。** Snowstorm 可以制作带透明贴图的 billboard 粒子。可将短命粒子布置在镜头前两侧，保留中心透明区，形成画面边缘的青绿氛围。它仍是世界空间效果，会受 FOV、宽高比、近裁剪、画质与渲染模式影响，必须先双人实测；不承诺是真正固定的屏幕图层。两人的演出机位相同时只发一套，避免重复叠加。
2. **`camera.fade` 只用于极短的切镜/命中闪色。** 当前 API 只有 RGB 与淡入、保持、淡出时间，没有指定最高透明度的参数；它最终会遮满画面，不适合用来持续蒙一层半透明绿膜。不能不断重发 fade 来模拟色调，否则容易出现闪烁或盖住动作。
3. **原生 JSON UI 色膜暂不采用先前的文字标记方案。** title/actionbar 已被用户排除，当前未验证另一个独立触发途径。若继续研究原生 UI，必须先证明有符合限制的数据通道；不能为了遮罩替换现有 HUD 或占用已被禁止的通道。

第一版推荐“边缘叶纹试样＋世界空间叶流/冲击”，用特写构图和明暗对比建立氛围。若镜头叶纹稳定性不足，先保留角色周围的深青背景粒子，不强行承诺稳定全屏色膜。

### 不占用文字通道的候选路线

- 额外的 TextPrimitive 实例可做演出题字，复用现有按镜头坐标摆放、按房间限制可见玩家的方法；保留原血条/气条/席位标签。它支持文字及 RGBA 背景，不提供任意 PNG 图片控件。
- 专用镜头前贴片实体可携带叶纹/渐变贴图，由脚本直接设置位置、可见性和动画；短命 billboard 粒子也能做边缘装饰。必须先验证透明材质、机位硬切、跟随延迟、近裁剪及不同 FOV，不能用已有角色的半透明失败方案直接套用。
- 两者都是世界空间表现，不等于真正固定屏幕坐标的 UI。第一步做一个可关闭、可清理的小原型，实机通过后再接三气。

以上效果均由脚本直接控制创建与结束，不向 title、subtitle 或 actionbar 发送控制标记。此前关于按阶段复用 actionbar 的提议已被用户明确否决。

## 后续制作顺序与验收

1. 先在 `tools/snowstorm/` 新建三个效果：手心聚叶、珍珠尾迹、镜头边缘叶纹试样。先只接三气开场，用户看过后再决定遮罩强度。
2. 再做首拳与多方位连击的击打方向、落点爆散，最后做普通与残血两套终结。
3. 使用全新的粒子 identifier 和贴图；现有七个粒子文件保留。确定风格后才将新效果接入资源包。
4. 所有效果按房间、施放者和本次技能管理。追击开始时收掉遮罩；挥空、被打断、KO、换局及玩家离开都能清理。长生命粒子难以单独撤销，第一版优先短命粒子按需发射，结束后很快自然消失。
5. 1P/2P、普通/残血、命中/失败、最后一击 KO、追击被打断分别验收；核对不同画幅下眼睛和手部不被挡住、头顶标签恢复、两名玩家看到同一演出。多房并发时检查帧率与粒子数量，再定最终发射上限。

固定招式题字可以后续加为单张美术贴图，短暂出现后消散；具体招式名、字体和位置先由用户确认。这轮建议先完成动作与光效层次，再加文字。
