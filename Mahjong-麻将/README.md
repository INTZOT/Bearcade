# 麻将(Mahjong)

Bearcade 小游戏包。当前包含 **牡丹江麻将** 预设玩法，以及自定义牌组/对局设置。

## 当前已实现

- **房间与人数**：8 个房间，每房 3~4 人；3 人局使用南/东/北三个座位。
- **房主机制**：最先加入的玩家为房主；房主离开/掉线后顺延；房主可用「书」或 `/mahjong:setup` 打开设置。
- **预设模式：牡丹江麻将**
  - 112 张牌：万/条/筒 1~9 ×4 + 红中 ×4。
  - 庄家对家开门，单骰留牌墩；每人先拿 3 墩两圈，再补 1 张，庄家多 1 张。
  - 自动摸牌、自动理牌、点击手牌打出；非自己回合不能出牌。
  - 吃（下家）、吃听（任意一家）、碰、明杠、暗杠、补杠、听、胡、过。
  - 严格动作优先级：胡 > 吃听 > 碰/杠 > 吃；同层按逆时针顺序（截胡/近家优先）。
  - 必须开门才能听；听牌后手牌暗置锁定，只能打保持听牌的牌。
  - 不能手把一：听牌后手牌至少剩 4 张。
  - 宝牌暗置不公开，只有听牌玩家知道；听牌玩家自摸宝牌直接胡（摸宝）；出现 3 张亮出的相同宝牌时换宝。
  - 暗杠在听牌前暗置、不计入换宝亮出计数；该玩家听牌后暗杠改为明置并开始计入。
  - 计分：未听点炮 3 分；听牌点炮 1 分/人；自摸 2 分/人；摸宝 3 分/人；宝中宝 6 分/人。
  - 流局：分数不变、庄家不变，房主可“下一局”重新发牌。
  - 胡牌：分数保留，房主可“下一局”；庄家胡牌连庄，闲家胡牌下家坐庄。
- **离线/离开托管**：预设模式下离线玩家整局保留座位，系统自动“摸哪张打哪张”；能胡时自动胡，不吃碰杠。
- **自定义模式**：可逐类目微调任意牌种，并设置自动开局/留牌/开牌/拿牌墩数/自动理牌/自动打出。
- **牌墙生成**：开局按选中牌洗牌，生成四面牌墙（牌垛），支持摸牌与剩余显示。
- **副露展示**：吃/碰/杠会实体摆放到对应玩家面前。
- **场地**：26×26 方形，中央骰子按钮，四侧计分按钮。
- **回座**：退出/返回大厅的玩家执行 `/mahjong:back` 可回到原房间座位。

## 麻将方块

- 已接入现成全套 `Mc-Mahjong`（暂无花牌）。
- ID 规则：`mahjong:mahjong_<a|b|c|d|e><1~9>`
  - `a` = 万，`b` = 条，`c` = 饼
  - `d` = 风（东南西北：`d1`~`d4`）
  - `e` = 字（中发白：`e1`~`e3`）
  - 花牌 `f` 暂未制作
- 每个方块含 12 种状态：`mahjong:pose = stand/down/up` × `minecraft:cardinal_direction = north/east/south/west`。
- 支持潜行+空手右键翻牌；手持砖类直接设定姿态；木棍改朝向；骨头切换暗置模式。
- 牌垛 `mahjong_stack_full` / `mahjong_stack_half` 用于摸牌显示。
- 同步脚本：`scripts/gen-mahjong-blocks.mjs`。

## 场地制作（首次运行前必做）

> **重要**：麻将方块使用自定义 Block States，世界必须开启实验 **Holiday Creator Features**，否则行为包可能无法加载。

1. `/bearcade:tmp tp mahjong` 进入模板维度；
2. 执行 `/function build_field` 生成场地；若函数未找到，可用 `/mahjong:buildfield`；
3. `/bearcade:tmp sz mahjong` 配置模板捕获范围；
4. `/bearcade:tmp ap mahjong` 应用到全部房间；
5. 用 `/bearcade:config mahjong` 核对/修改配置。

## 常用命令

- `/mahjong:back`：回到自己所在的麻将房间座位；
- `/mahjong:setup`：打开房主设置；
- `/bearcade:tmp tp|ap|sz mahjong`：模板维度开发；
- `/bearcade:config mahjong`：运行时配置；
- `/bearcade:quit`：在房间维度强制中止。

## 自定义模式对局设置

- **自动开局**：自动按规则发牌；
  - 留牌：不留 / 确定墩数 / 骰子决定；
  - 开牌位置：对家开门 / 单骰开门；
  - 单次拿取墩数：1 / 2 / 3 / 6；
- **自动理牌**：手牌自动排序并摆在面前；
- **自动打出**：空手右键面前手牌方块即可打出。
