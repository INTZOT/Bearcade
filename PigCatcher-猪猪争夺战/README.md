# 猪猪争夺战(PigCatcher)

Bearcade 派对小游戏包:红黄蓝绿四队用钓鱼竿/胡萝卜钓竿/拴绳把中立猪赶进自家核心区,时间结束后按核心区猪数结算。房间管理复用 `shared/minigame-core`,玩法在 [src/game.ts](src/game.ts)。

## 已确认规则

- 每房 4~16 人,2 个房间,支持派对模式;
- 开局玩家随机均分红/黄/蓝/绿四队,头顶名牌与聊天名字按队伍颜色渲染;
- **道具三件套**:钓鱼竿(脚本牵引,勾中猪后拉向持竿玩家)、胡萝卜钓竿(原版跟随)、拴绳 ×3(原版拴绳);开局发放,死亡在队出生点复活并重新发放;
- **猪**:中立猪(`minecraft:pig`),默认开局在场地中心刷 5 只(±3 随机偏移),之后每 20 秒补充 1 只;猪不可被伤害/击杀;出地图边界或掉虚空会被传送回中心刷新点(被拴绳拴住时跳过,避免与玩家拉扯);
- **核心区引力场**:每队核心区对附近猪施加胡萝卜引力(默认半径 6 格),帮助把猪"吸"进核心区;
- **归属与计分**:每 tick 按猪当前所在核心区实时归属;侧边栏显示四队猪数,actionbar 显示队名/剩余时间/四队猪数;
- **结算**:默认 5 分钟到,按核心区猪数判定,最高分并列获胜并公告各队猪数;全 0 平局,随后返回大厅;
- **PVP**:异队可互伤、同队免伤;任一队全员退出时对局提前结束;
- **队伍装备实体储存**:四队独立仓库实体(`bearcade:pigcatcher_loadout_dummy` + nameTag 分队),开局/复活按队自动覆盖全套物品(背包/快捷栏/盔甲/副手);在 `/bearcade:config pigcatcher` 的「XX队装备配置」里"保存当前玩家装备"/"清空"(未配置即空背包开局);
- 全部规则数值与坐标经 `/bearcade:config pigcatcher` 运行时可改(对局中禁止):准备房间坐标、地图边界、猪刷新点、初始猪数/补充数量/刷新间隔、游戏时长、核心区吸引半径/强度、四队出生点与核心区。

## 场地制作

`src/config.ts` 中场地坐标为**默认占位值**,模板场地建好后需核对/调整:

1. `/bearcade:tmp tp pigcatcher` 进入模板维度 `bearcade:pigcatcher_template`;
2. 建造场地(四队出生点、核心区、猪活动区,参考 `src/config.ts` 默认布局:四向各一队);
3. `/bearcade:tmp sz pigcatcher` 配置模板捕获范围,`/bearcade:tmp ap pigcatcher` 应用到全部房间;
4. `/bearcade:config pigcatcher` 核对并修改:地图边界、四队出生点与核心区、猪刷新点等。

> 结构上限 64×384×64;常加载区域只需覆盖实际内容(y -1~65),不要整列 384 层。

## 常用命令

- `/bearcade:tmp tp pigcatcher` / `sz` / `ap`:模板维度开发;
- `/bearcade:config pigcatcher`:规则数值、坐标与装备配置(对局中禁止);
- `/bearcade:quit`:在房间维度执行,强制中止对局;
- `/bearcade:debug pigcatcher enable|disable`:调试日志。

详细规范见仓库根目录 `development.md`。
