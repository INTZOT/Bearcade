# 工作室(Studio)

Bearcade 小游戏包:**合成制作交付类**。玩家在封闭工作室中采集货架原材料,使用工作台/熔炉合成每回合指定的目标物品,前三名完成者得分。

## 玩法规则

- 每房 2~8 人,2 个房间,支持派对模式(派对模式不限人数,可超过 8 人);
- 游戏共 **7 回合**(可在 `/bearcade:config studio` 调整);
- 每回合从题库随机抽取一个目标物品(题库可调);
- 玩家使用货架上的原材料 + 工作台/熔炉合成目标物品;
- 背包里出现目标物品即判定成功:
  - 清空该玩家背包并提示“制作成功”;
  - 提交成功时**立即加分**,本回合前三名完成者分别获得 **+3 / +2 / +1** 分(可调);
- 无人完成时,60 秒后进入下一回合,所有人不加分;
- 第一名完成后,10 秒后进入下一回合,期间其他玩家仍可完成并拿分;
- 房间内禁止玩家互相攻击;
- 每回合重置时:
  - 清空场地内掉落物;
  - 重置所有熔炉内部(包括燃烧中的熔炉),防止上一回合遗留;
  - 复原货架原材料;
- 对局过程中持续给玩家饱和效果,防止饿死;
- 已提交成功的玩家会被传送回出生点并持续清空背包;场地掉落物只在回合更换时统一清理,避免影响玩家挖掘收集;
- Actionbar 显示当前回合目标与玩家总分,HUD 显示本回合剩余时间与当前总分前三名;
- 游戏结束后公布最终总分前三名并返回大厅。

## 原材料与场地

- 场地为封闭工作室:地板、墙壁、玻璃天花板、中央工作台/熔炉、四周货架;
- 货架上的原材料方块可挖掘采集,每回合开始时自动复原并补充;
- 默认原材料:`oak_log`、`stone`、`white_wool`、`coal_ore`、`iron_ore`、`gold_ore`、`quartz_ore`、`redstone_ore`(可调);
- 场地内熔炉为**秒烧模式**:放入可烧炼原材料 + 燃料后立即在输出槽生成产物;燃料仅作为点燃条件,不会被额外消耗(当前支持铁矿石→铁锭、金矿石→金锭、沙子→玻璃、圆石→石头、原木→木炭等);
- 默认题库:`furnace`、`crafting_table`、`bed`、`barrel`、`bucket`、`activator_rail`、`redstone_comparator`(可调)。

## 地图构建指令

管理员在模板维度执行:

```text
/studio:build           生成默认尺寸(21×21)工作室
/studio:build 31        生成指定边长(奇数,11~41)
```

生成后请用 `/bearcade:tmp sz studio` 配置模板范围,再执行 `/bearcade:tmp ap studio` 应用到全部房间。

## 常用命令

- `/studio:build [size]`:模板维度生成工作室地图(仅管理员, op tag);
- `/bearcade:config studio`:调整回合数/超时/分数/题库/原材料/坐标等(对局中禁止);
- `/bearcade:tmp tp studio` / `sz` / `ap`:模板维度开发;
- `/bearcade:quit`:在房间维度执行,强制中止对局;
- `/bearcade:debug studio enable|disable`:调试日志。

## 配置项

| 配置 | 说明 |
| --- | --- |
| 准备房间坐标 | Core 入房传送点 |
| 普通模式最大人数 | 默认 8,派对模式忽略 |
| 总回合数 | 默认 7 |
| 单回合超时(秒) | 默认 60 |
| 第一名后等待(秒) | 默认 10 |
| 第一/二/三名得分 | 默认 3/2/1 |
| 地面 Y | 地图生成使用的地面高度 |
| 默认场地尺寸 | `/studio:build` 默认边长 |
| 题库管理 | 目标物品 ID 列表,逗号分隔 |
| 原材料列表 | 货架可挖掘方块 ID 列表,逗号分隔 |

## 开发/部署

```bash
npm run typecheck
npm run check
npm run build
npm run package
```

安装到测试存档时,将 `Studio-工作室` 复制到世界 `behavior_packs/`,将 `resource-pack` 内容复制到 `resource_packs/Studio-工作室-资源包/`,并在 `world_behavior_packs.json` / `world_resource_packs.json` 注册对应 pack_id。

详细规范见仓库根目录 `development.md`。
